# Sterrenwyck — drie merkrichtingen

Voorbeeldwebsites gemaakt door Spring Marketing Agency om drie visuele richtingen voor het project Sterrenwyck (Haarlem) te tonen.

- `onder-de-sterren/` — astronomisch, nachtblauw + koper
- `de-nieuwe-tuinstad/` — tuinstad, hofgroen + kalkwit
- `wyck/` — editorial, baksteenrood + papier

Dit is **niet** de officiële projectwebsite van Sterrenwyck en niet uitgegeven door EFY Group of INBO. Woningtypen, oppervlakten en afstanden zijn indicatief. De inschrijfformulieren zijn niet functioneel en slaan geen gegevens op.
